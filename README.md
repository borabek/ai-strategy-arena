# AI Strategy Arena

Full-stack AI-powered strategy game platform built with Next.js, FastAPI, SQLAlchemy and Docker.

## Project Overview

AI Strategy Arena allows users to play classic strategy games against AI opponents, track performance statistics, replay previous matches, and compete on leaderboards.

The project was designed to demonstrate full-stack development skills, backend API design, database modelling, authentication systems, and AI-based decision making.

---

## Features

### Authentication
- User registration and login
- JWT-based authentication
- Protected API endpoints

### AI Games
- Tic Tac Toe
- Connect 4
- AI move generation
- Strategy evaluation

### Match System
- Save completed matches
- Match history tracking
- Replay previous games

### Leaderboards
- Player rankings
- Win rate tracking
- Performance statistics

### AI Simulations
- AI vs AI matches
- Automated game simulations
